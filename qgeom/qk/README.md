# `qgeom/qk/` — 四元數凱勒曲率張量群空間 × 雙射緊緻四元雅可比簇

> **架構位置**：`architecture.json` 的套件 `qgeom-qk`，聯邦 `accel`（qgeom 子聯邦），**Layer 3**，
> `depends_on: [qgeom-core]`。只匯入 `qgeom/core` 與 `moonbitlang/core`。

## 1. 一句話定位

把「四元數凱勒流形的曲率張量」與「雙射緊緻四元雅可比簇的恆等張量幾何矩陣」寫成**兩個具體的有限對象**：

* **李代數側**：`sp(2)`（10 維）的 Cartan 分解 `sp(2) = k ⊕ m`，`k = sp(1) ⊕ sp(1)`、`m ≅ H`；
  對稱空間曲率 `R(X,Y)Z = −[[X,Y],Z]`。四元數凱勒結構 `I, J, K` 就是 `k` 的兩個 `sp(1)` 因子在 `m` 上的
  左乘／右乘作用，而「曲率落在 `sp(1) ⊕ sp(n)`」在這裡是一個可判定的等式。
* **格子側**：`H^g / Λ`（`g = 1, 2`）上的整數結構矩陣 `I, J, K`（`det = 1`、`I² = −id`、`IJ = K`），
  它們把格點**雙射**到自己；極化形式 `Ω` 單模、反對稱，且被 `Sp(2g, Z)` 保持
  —— 這就是「恆等張量幾何矩陣」的 `Sp` 不變性。

## 3. 得到的定理（含算出的數字）

### 3.1 `sp(2)`：基底、封閉性、Jacobi（5 命題）

基底大小 **10**（`sp(2)` 的實維數）；10 個元素全部 `X† = −X`；攤平矩陣的**秩 = 10**；
`[X,Y] ∈ sp(2)` 對 **10² 對**成立；**Jacobi** 對 **1000 組**成立。

### 3.2 Cartan 分解 `sp(2) = k ⊕ m`（6 命題）

| 標籤 | 敘述 | 驗證 |
|---|---|---|
| 維數 | `10 = 6 + 4` | 基底 |
| `[k,k] ⊂ k` | **36/36** 次交換子都在 `k` 內 | 座標可解 |
| `[k,m] ⊂ m` | 24 次 | 座標可解 |
| **`[m,m] ⊂ k`** | 16 次 —— 對稱空間的核心條件 | 座標可解 |
| 正交 | `k ⊥ m`（Hermitian 內積實部，36 對全零） | 精確 |
| 因子正交 | `k` 的兩個 `sp(1)` 因子互相正交（9 對） | 精確 |

### 3.3 四元數凱勒結構與曲率的落點（6 命題）

`sp(1)_L` 在 `m ≅ H` 上是**左乘**：`[X_a, M_b] = M_{σ_a·b}`（12 個組合）；
`sp(1)_R` 是**右乘**：`[Y_a, M_b] = M_{−b·σ_a}`（12 個組合）；
`I² = J² = K² = −1`、`IJ = K`、`IJK = −1`；
**曲率落點**：`R(X,Y)Z ∈ m`（16 對 × 4 個 `Z`）；
**曲率與 `k` 的交集只有 0**：`R(X,Y)Z ∈ k ⇔ R(X,Y)Z = 0`（64 個三元組中 40 個為零，24 個非零）。

### 3.4 曲率恆等式（4 命題）

前兩名額反對稱 `R(Y,X)Z = −R(X,Y)Z`（4³ 組）；
後兩名額反對稱與**配對對稱** `⟨R(X,Y)Z,W⟩ = −⟨R(X,Y)W,Z⟩ = ⟨R(Z,W)X,Y⟩`（256 組）；
**第一 Bianchi** `R(X,Y)Z + R(Y,Z)X + R(Z,X)Y = 0`（4³ 組）；
負控制：64 個三元組中 **24 個非零** —— Bianchi 不是對著零算子空轉。

### 3.5 雙射緊緻四元簇（8 命題）

| 標籤 | 敘述 |
|---|---|
| 整數性 | `I, J, K` 都是整數矩陣（格子不變） |
| 單模 | `det I = det J = det K = 1` ⇒ 把 `Z⁴` **雙射**到自己 |
| 複結構 | `I² = J² = K² = −id` |
| 四元數關係 | `IJ = K`、`JK = I`、`KI = J`（矩陣乘法） |
| 恆等張量 | `Iᵗ·id·I = id`（`I, J, K` 都是格子自同構） |
| **雙射** | 盒 `[−1,1]⁴` 的 **81** 個點在 `I` 下**每個恰好被擊中一次** |
| 軌道分解 | `81 = 1 + 4·(21 − 1)`（1 個固定點、21 條軌道），與公式一致 |
| 負控制 | `det(2I) = 16 ≠ 1` ⇒ `2I` 不是格子自同構 |

### 3.6 極化形式與恆等張量幾何矩陣（10 命題）

`Ω = dx₀∧dx₁ + dx₂∧dx₃`：整數、反對稱 `Ωᵗ = −Ω`、**`det Ω = 1`**（單模極化 ⇒ 緊緻）；
**`Mᵗ Ω M = Ω`** 對 4 個 `Sp(2,Z)` 分塊生成元成立，`g = 2`（`H²/Z⁸`）時同一條在 **8×8** 上成立；
`Ω(X,Y) = ⟨IX,Y⟩`（極化就是 `I` 的 Kähler 形式）；
四元數 Hermitian 形式 `h(y,x) = conj h(x,y)`、`h(x,x) = (6,0,0,0) = ‖x‖² > 0`；
`I` 是 `ω` 的 Kähler 結構（`ω(IX,IY) = ω(X,Y)`、`ω(X,IX) = ‖x‖² > 0`）；
`J`、`K` **反相容**（`ω(JX,JY) = −ω(X,Y)`）—— 同一族裡只有一個 Kähler 形式。

## 4. 邊界

「雅可比簇」在這裡是**具體的緊緻四元環面 `H^g/Λ`**（`g = 1, 2`）模型：整數結構矩陣、單模極化、
`Sp(2g,Z)` 不變的恆等張量。它**不是**代數曲線的 Jacobian variety，也沒有 theta 函數或模形式的內容。
「四元數凱勒流形」在這裡是**對稱空間 `Sp(n)/(Sp(1)×Sp(n))` 的李代數模型**（`n = 2`），
曲率用 `R(X,Y)Z = −[[X,Y],Z]` 的典範值，不涉及度量選擇或整體拓撲。
