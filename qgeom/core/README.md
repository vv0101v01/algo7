# `qgeom/core/` — 精確四元數 × 軸向交換張量變體

> **架構位置**：`architecture.json` 的套件 `qgeom-core`，聯邦 `accel`（qgeom 子聯邦），**Layer 0**，
> `depends_on: []`。只匯入 `moonbitlang/core`。

## 1. 一句話定位

提供 qgeom 其餘四個套件共用的**精確算術與張量代數底層**，並在此之上把「軸向交換張量變體」
（axis-swap tensor variants）做成三個可以重算的算子家族：

* **變體一 `τ`（交換）**：`τₐ² = id`、線性、滿足 **Yang–Baxter** 與 **S_n Coxeter** 關係；
  秩 3 時 `τ₀₁`／`τ₁₂` 生成 `S₃`，長元素兩種寫法都給出 `[2,1,0]`。
* **變體二 `σ`（帶號，`σ = −τ`）**：`σ² = id`、帶號 braid 多一個 `−1`、`σ 不變 ⇔ τ 反不變`。
* **變體三 `ρ`（循環）**：`ρ³ = id`、`ρ = τ₀₁∘τ₁₂`、`ρ² = τ₁₂∘τ₀₁`，並用 **Burnside 引理**
  數實數張量上的軌道數 `(d³+2d)/3`。

三者在**任意秩**上由同一個 `ct_permute` 引擎實現，因此「交換兩軸」不是針對秩 2、3 硬寫的特例。

## 3. 得到的定理（含算出的數字）

### 3.1 精確有理數體（7 命題）

| 標籤 | 敘述 |
|---|---|
| 正規形 | `6/−4`、`−6/−4`、`0/−5` 都化到分母為正、`gcd = 1`，且等值判定是結構比較 |
| 體公理 | 交換、結合、分配、單位、加乘反元素（對 `−3/7, 0, 11/4` 等樣本） |
| 除零 | `qq_inv(0) = None`（真的不存在）與 `qq_div(x,0) = 0`（全約定）**分開** |
| 稠密 | 任意 `a < b` 都存在 `(a+b)/2` 嚴格介於其間 |

### 3.2 四元數環 H（11 命題）

| 標籤 | 敘述 | 驗證 |
|---|---|---|
| 基本關係 | `i² = j² = k² = ijk = −1` | 精確 |
| 非交換 | 81 個整四元數樣本共 6,561 對中 **5,616** 對 `xy ≠ yx`；`ij ≠ ji` | 計數 |
| 結合律 | 81³ 組 | 全量 |
| 範數乘法性 | `N(xy) = N(x)N(y)`（Lagrange 四平方） | 6,561 對 |
| 共軛 | `conj(xy) = conj(y)conj(x)`、`x·conj(x) = N(x)` | 全量 |
| **無零因子** | 6,561 對中 **0** 對 `xy = 0` 且 `x,y ≠ 0` | 反例搜尋 |

### 3.3 左／右正則表示（5 命題）

`L(x)L(y) = L(xy)`、`R(x)R(y) = R(yx)`、`L(x)·v = x·v`、`R(x)·v = v·x`、非零元素 `rank L(x) = 4`。
右乘是**反**同態——這條在第一輪寫成 `R(x)R(y) = R(xy)` 被定律抓出來，是本輪唯一被自動化糾正的代數錯誤。

### 3.4～3.5 軸向交換三變體

| 章 | 命題 | 內容 |
|---|---:|---|
| τ² = 1 與線性 | 5 | 秩 2/3/4 共 8 個相鄰位置：`τ²T = T`、`τ(aT+bU) = aτT+bτU`、`τ` 不改展平的多重集 |
| Yang–Baxter 與 Coxeter | 6 | `τ₀₁τ₁₂τ₀₁ = τ₁₂τ₀₁τ₁₂`（顯式 `= [2,1,0]`）；秩 4 兩處 braid、`\|i−j\| ≥ 2` 交換、S₄ 長元素兩種字都 `= [3,2,1,0]` |
| σ = −τ | 5 | `σ² = id`、`σ₀₁σ₁₂σ₀₁ = −(τ₁₂τ₀₁τ₁₂)`、`σ` 不變 ⇔ `τ` 反不變、`σ ≠ τ`（負控制） |
| ρ 循環 | 7 | `ρ³ = id`、`(ρT)[a,b,c] = T[b,c,a]`、`ρ = τ₀₁∘τ₁₂`、`ρ² = τ₁₂∘τ₀₁`、Burnside `(d³+2d)/3`（d = 2,3,4 ⇒ 4, 11, 24） |
| 交換表與純張量 | 5 | 三變體兩兩的合成表、純張量 `u⊗v⊗w` 在 `τ`／`ρ` 下的像 |

### 3.6 對稱／反對稱分解（6 命題）

`p_s = (id+τ)/2`、`p_a = (id−τ)/2`：`p_s² = p_s`、`p_a² = p_a`、`p_s p_a = 0`、`p_s + p_a = id`；
維度由**投影後基準家族的秩**實算：`dim Sym = (N+F)/2`、`dim Alt = (N−F)/2`（d = 3 時 18 / 9）。
負控制：探針不是不變量、`p_s ≠ id`。

## 4. 流程

* **輸入**：無（純函式，不讀檔、不讀參數）。
* **輸出**：`qgeom_core_laws() -> Array[(String, Bool)]`，由 `cmd/qgeom` 逐條印出。
* 唯一的狀態是 `BigInt`；沒有浮點、沒有隨機、沒有 `eps`。
