# `qgeom/geom/` — 平移射影 × 雅可布全射張量積

> **架構位置**：`architecture.json` 的套件 `qgeom-geom`，聯邦 `accel`（qgeom 子聯邦），**Layer 2**，
> `depends_on: [qgeom-core]`。只匯入 `qgeom/core` 與 `moonbitlang/core`。

## 1. 一句話定位

兩件事，兩章一組、各配負控制：

* **平移射影（translation-projective）**：平移 `x ↦ x + t` 只在仿射圖上是一條公式；
  在射影空間裡它必須換成齊次矩陣 `M(t) = [[I, t], [0, 1]]`。這裡真的把它算出來並證明：
  它是**唯一的**射影提升（最後一列 `(0,…,0,1)`）、滿足群律、保無窮遠超平面、`det = 1`、
  `(M−I)² = 0`（拋物元素）且**無限階**；交比在它與任意分式線性映射下不變。
* **雅可布全射張量積（Jacobian surjective tensor product）**：把「雅可比是函子」與
  「張量積怎麼搬秩」變成精確多項式運算：鏈鎖律逐點相等、`rank(A⊗B) = rank A · rank B`、
  全射 ⊗ 全射 = 全射、以及 `dim ker(A⊗B) = 列積 − rank A · rank B`。

## 3. 得到的定理（含算出的數字）

### 3.1 平移的射影提升（13 命題）

| 標籤 | 敘述 |
|---|---|
| 形狀 | 提升為 3×3，最後一列 `(0,0,1)`（唯一性由此釘住） |
| 群律 | `M(t)·M(s) = M(t+s)`；`M(0) = id`；`M(−t)M(t) = id`（雙射） |
| 行列式 | `det M(t) = 1` |
| 無窮遠 | 無窮遠點 `(1,2,0)` 的像仍是無窮遠點（`w = 0`） |
| 仿射圖 | `[3,−1,1] ↦ [4,1,1]` |
| 負控制 | 平移後的點 ≠ 原點（不是恆等映射） |
| **拋物性** | `(M(t) − I)² = 0`（在無窮遠處只有一個不動點） |
| **無限階** | `M(t)^k = M(kt) ≠ id`，`k = 1..5` |
| 關聯性 | `2x−y−5 = 0` 上的 `(3,1)`，其像落在像直線上；離線點的像也離線 |
| 零判定 | `proj_is_zero` 認得零向量、不誤判非零向量 |

### 3.2 交比不變（5 命題）

`(0,1;7/2,5) = 28/25`（與手算一致）；平移 `x ↦ x + 4/3` 不改交比；
**4 個分式線性映射**（含 `det ≠ 1` 與 `x ↦ −1/x`，後者把 `0` 送到無窮遠）全部不改交比；
退化守衛：`b = c` 時交比分母為零 ⇒ `None`；負控制：換一個點交比就變。

### 3.3 調和共軛與對稱恆等式（6 命題）

`(a,b;c,d) = (c,d;a,b) = (b,a;d,c)`、`(a,b;c,d)·(a,b;d,c) = 1`、
調和共軛公式 `d = ((a+b)c − 2ab)/(2c − a − b)` 給出 `3/5` 並使 `(a,b;c,d) = −1`、
交比只依賴射影類（`[3/5,1]` 與 `[3,5]` 同值）、負控制 `d = 2` 不是調和點。

### 3.4 雅可比是函子（4 命題）

`J(g∘f)(x) = J_g(f(x))·J_f(x)` 在 3 個點上**精確相等**；`(g∘f)(1,2) = (5,6)`；
線性映射的雅可比恆等於其矩陣；**平移映射的雅可比恆為 `I`**（射影平移的線性化是恆等）。

> 這一章抓出一個真正的 bug：多項式複合若**依序**代換 `x₀`、`x₁`，
> 會把先前代換進來的 `x₁` 再代換一次。改為 `mpoly_substitute_all` 同時代換後，
> 代值核對（`(g∘f)(1,2) = (5,6)`）才與鏈鎖律同時成立。

### 3.5 張量積的秩與全射性（7 命題）

| 標籤 | 敘述 | 驗證 |
|---|---|---|
| 秩乘法性 | `rank(A⊗B) = rank(A)·rank(B)` | 25 對矩陣、精確秩 |
| 核維數 | `dim ker(A⊗B) = 列積 − rank(A)·rank(B)` | 25 對 |
| 全射封閉 | 全射 ⊗ 全射 = 全射（`rank = 4 = 列積`） | 精確 |
| 負控制 | 秩 1 的奇異矩陣張量積後仍秩虧（不滿射） | 精確 |
| 行列式 | `det(A⊗B) = det(A)²det(B)² = 100`（2×2 情形） | 精確 |
| 淹沒 | 滿秩點 `rank J = 2`、`rank(id⊗J) = 4` = 目標維度 | 精確 |
| 負控制 | 奇異點 `(0,0)` 上 `rank J = 1`，`id⊗J` 不滿射 | 精確 |

## 4. 流程

* **輸入**：無。
* **輸出**：`qgeom_geom_laws() -> Array[(String, Bool)]`，由 `cmd/qgeom` 逐條印出。
* 全部算術走 `QQ`（`BigInt` 有理數），所以「精確相等」是真的相等，不是容差比較。
