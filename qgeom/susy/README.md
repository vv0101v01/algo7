# `qgeom/susy/` — 超對稱四元數頂點對偶 × 複形四元數德朗姆型恆等

> **架構位置**：`architecture.json` 的套件 `qgeom-susy`，聯邦 `accel`（qgeom 子聯邦），**Layer 2**，
> `depends_on: [qgeom-core]`。只匯入 `qgeom/core` 與 `moonbitlang/core`。

## 1. 一句話定位

這裡的「超對稱」是一個可以逐項檢查的分次代數，不是比喻：

* `Z₂` 分次元素、**分次交換子** `[A,B] = AB − (−1)^{|A||B|}BA`、**分次 Jacobi**、**實超跡** `str`。
* **四元數頂點對偶方程**：頂點算子 `V(z) = Σ A_n z^{−n−1}` 的對偶 `V*(z) = Σ A_n† z^{−n−1}` 滿足
  `⟨A_n u, w⟩ = ⟨u, A_n† w⟩` 逐模成立，且 `V** = V`。
* **複形四元數德朗姆型恆等**：有限單純複形上 `∂² = 0`、Betti 數、Hodge 定理、超電荷 `Q² = ⊕Δ_k`、
  `Z₂` 分次，在 `Q` 上與 `H ⊗_R C` 上各算一次。

## 3. 得到的定理（含算出的數字）

### 3.1 超對稱代數（6 命題）

| 標籤 | 敘述 | 驗證 |
|---|---|---|
| 分次反對稱 | `[A,B] = −(−1)^{\|A\|\|B\|}[B,A]` | 4² 對 |
| 宇稱加法 | `\|[A,B]\| = \|A\| + \|B\| (mod 2)` | — |
| **分次 Jacobi** | `(−1)^{\|A\|\|C\|}[A,[B,C]] + (−1)^{\|A\|\|B\|}[B,[C,A]] + (−1)^{\|B\|\|C\|}[C,[A,B]] = 0` | 64 組 |
| 實超跡 | `str(EE') = str(E'E)`、`str(OO') = −str(O'O)`（值 **−5 / 3**） | 分塊宇稱 |
| 交換子超跡 | `str([A,B]) = 0` | 4² 對 |
| 負控制 | 偶元素**乘積**的實超跡 `= −5 ≠ 0`（只有分次交換子保證為零） | — |

> **為什麼是「實」超跡**：四元數不可交換，`tr(AB) = tr(BA)` 對四元數係數不成立
> （1×1 分塊時就退化成 `ab ≠ ba`），但 `Re tr(AB) = Re tr(BA)` 成立。
> 因此這裡的超跡取實部，並且用 `str([A,B]) = 0` 與負控制把這個選擇釘在可檢驗的位置上。
> 同時也意味著：宣告為「偶」的矩陣必須是 (1|1) **分塊對角**、奇必須是**非對角**，否則超跡的循環性會直接失敗。

### 3.2 四元數頂點對偶幾何方程（7 命題）

Hermitian 配對 `⟨u,w⟩ = Σ Re(conj(u_i) w_i)` 對稱、正定（`⟨u,u⟩ = 15 > 0`）、`⟨0,0⟩ = 0`；
伴隨性 `⟨Au,w⟩ = ⟨u,A†w⟩ = 5`；**頂點對偶方程逐模成立（6 個模）且 `V** = V`**；
截斷頂點代數的**結合律** `(V·W)·U = V·(W·U)`（前 3 階係數逐位元相同）；
零階卷積就是矩陣乘積；負控制：非 Hermitian 模的對偶不是自己（`V* ≠ V`）。

### 3.3 德朗姆型恆等（7 命題 × 5 個複形）

| 複形 | 頂點／邊／面 | Betti `(β₀,β₁,β₂)` | Euler |
|---|---|---|---|
| 單一三角形（圓盤） | — | `(1,0,0)` | 1 |
| 四面體邊界（S²） | — | `(1,0,1)` | 2 |
| 八面體表面（S²） | — | `(1,0,1)` | 2 |
| 3×3 週期環面（T²） | 9 / 27 / 18 | `(1,2,1)` | 0 |
| RP² 的 6 頂點三角剖分 | — | `(1,0,0)` | 1 |

恆等（每個複形都驗）：

* `∂_{k−1}∂_k = 0`（**精確零矩陣**，不是「接近零」）；
* **Euler 兩條路徑**：`Σ(−1)^k n_k = Σ(−1)^k β_k`；
* **Hodge 定理**：`dim ker Δ_k = n_k − rank Δ_k = β_k`；
* **超電荷恆等**：`Q² = ⊕_k Δ_k`（矩陣逐項相等），其中 `Q = D + Dᵗ`、`D = ⊕_{k≥1} ∂_k`；
* **`Z₂` 分次**：`Q` 把偶次鏈送到奇次鏈（偶-偶、奇-奇塊全零）；
* **上鏈**：轉置算出的 Betti 數與鏈的相同。

### 3.4 複形四元數 `H ⊗_R C`（8 命題）

`i² = −1`、`J² = −1`（`J(x) = i·x`）、`(1+i)² = 2i`、複共軛是反自同構；
環面（`∂₁` 為 9×18）與 RP² 在 `H ⊗ C` 上仍 `∂∂ = 0`；
**伴隨恆等** `⟨∂a,b⟩ = ⟨a,∂ᵗb⟩`；**複結構與邊界算子交換** `J(∂a) = ∂(Ja)`；
複形化把每個係數從 4 個實座標擴成 8 個。

## 4. 邊界

「超對稱」＝ 分次代數 ＋ 有限複形上的 `Q² = Δ`，這是**數學結構**，不是量子場論模型；
頂點算子是**截斷**到前幾階的形式級數（結合律只對被比較的係數驗），
不是無限維頂點代數的收斂性陳述。
