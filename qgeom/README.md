## 3. 五個套件在做什麼

### 3.1 `qgeom/core` — 精確四元數與軸向交換張量變體（57 命題）

* **有理數體**：`QQ` 永遠保持正規形，因此等值判定是兩個 `BigInt` 的結構比較；`qq_inv` 是選項型（零真的沒有反元素），`qq_div` 才是除零回 0 的全約定。兩者分開，是為了讓「真的不存在」與「約定值」不被混為一談。
* **四元數環**：`i² = j² = k² = ijk = −1`、`ij ≠ ji`（81² 對樣本裡 5,616 對不可交換）、結合律（81³ 組）、共軛反自同構、**範數乘法性**（Lagrange 四平方）、`x·conj(x) = N(x)`、**無零因子**（81² 對中 0 對）。
* **正則表示**：`L(x)L(y) = L(xy)`、`R(x)R(y) = R(yx)`（右乘是反同態，這條一開始寫錯方向、被定律抓出來）、`L(x)·v = x·v`、非零元素的 `L(x)` 秩為 4。
* **軸向交換變體**：
  * `τₐ` 交換相鄰兩軸：`τ² = id`、線性、對秩 2/3/4 的 8 個相鄰位置全部成立；
  * **Yang–Baxter**：`τ₀₁τ₁₂τ₀₁ = τ₁₂τ₀₁τ₁₂`，並顯式驗證它等於反向置換 `[2,1,0]`；秩 4 的兩處 braid、`|i−j| ≥ 2` 的交換律、以及 S₄ 長元素兩種相鄰交換字都給出 `[3,2,1,0]`；
  * **帶號變體** `σ = −τ`：`σ² = id`、帶號 braid `σ₀₁σ₁₂σ₀₁ = −(τ₁₂τ₀₁τ₁₂)`、`σ 不變 ⇔ τ 反不變`；
  * **循環變體** `ρ`：`ρ³ = id`、顯式 `(ρT)[a,b,c] = T[b,c,a]`、`ρ = τ₀₁∘τ₁₂`、`ρ² = τ₁₂∘τ₀₁`，以及 **Burnside 軌道數** `(d³+2d)/3`（d = 2,3,4 實數軌道）；
  * **對稱／反對稱分解**：`p_s² = p_s`、`p_a² = p_a`、`p_s p_a = 0`、`p_s + p_a = id`，且 `dim Sym = (N+F)/2`、`dim Alt = (N−F)/2` 是用**投影後基準家族的秩**實算的（d = 3 時 18 / 9）。
  * 每一章都配一個負控制（探針不是不變量、相鄰算子不可交換、`σ ≠ τ`、`ρ ≠ τ`），避免「在一張對稱張量上空轉」。

### 3.2 `qgeom/hal` — 高維合體運算的硬體抽象層（20 命題）

* 抽象邊界是 `FusedBackend`：只承諾「名字、向量道寬度、分塊跨度」，**不承諾走訪順序**。
* 三個具體後端（純量 `ScalarCore`、道內交錯 `LaneCore`、分塊 `BlockedCore`）用不同的位置順序填輸出；18 條可執行計畫 × 7 個後端 = 126 次比較**逐位元相同**——這就是「抽象層」的可檢驗定義。
* **合體恆等**：`contract(τ₀₁T, 0) = contract(T, 1)`（先交換再收縮 = 直接收縮另一軸），以及全收縮不變量 `sum(τT) = sum(T)`、`sum(cT) = c·sum(T)`。
* **合併代數**：計畫串接結合律、`exec(p∘q) = exec(q)∘exec(p)`、`plan_simplify` 保存語意且冪等（6 條計畫共省下 4 步）。
* **流量模型**：三連逐元素步未合併 = 3N = 36，合併後 = N = 12；`fused ≤ unfused` 且在 3 條計畫上嚴格下降。
* **分塊與道**：312 組 `(n, span)`（n = 1..39、span = 1..8）分塊**恰好覆蓋每個位置一次**；28 組 `(後端, n)` 的走訪順序都是 `0..<n` 的排列（位置總和 = `n(n−1)/2`）；312 組 `(n, lane)` 的道覆蓋足夠且浪費 < lane。
* **純度**：跑兩次同結果、輸出是新緩衝（改輸出不動輸入）、計畫不就地改寫輸入。

### 3.3 `qgeom/geom` — 平移射影與雅可布全射張量積（35 命題）

* **平移的射影提升**：`M(t)M(s) = M(t+s)`、`M(0) = id`、`M(−t)M(t) = id`、`det = 1`；無窮遠點 `(1,2,0)` 的像仍在無窮遠處；仿射圖上 `[3,−1,1] ↦ [4,1,1]`；`(M−I)² = 0`；`M(t)^k = M(kt) ≠ id`（k = 1..5）；直線關聯性 `Lᵗp = 0 ⇒ (M⁻ᵗL)ᵗ(Mp) = 0`。
* **交比**：`(0,1;7/2,5) = 28/25`（與手算一致）、平移 `x+4/3` 下不變、4 個分式線性映射（含 `det ≠ 1` 與 `x ↦ −1/x`，後者把點送到無窮遠）下不變、`(a,b;c,d) = (c,d;a,b) = (b,a;d,c)`、`(a,b;c,d)·(a,b;d,c) = 1`、調和共軛公式給出 `−1`、`[3/5,1]` 與 `[3,5]` 給同一個交比（只看射影類）。
* **雅可比是函子**：`J(g∘f)(x) = J_g(f(x))·J_f(x)` 在 3 個點上精確成立；複合映射代值 `(g∘f)(1,2) = (5,6)`；線性映射的雅可比恆等於矩陣；平移映射的雅可比恆為 `I`。
  * 這裡抓到一個真 bug：多項式複合若**依序**代換 `x₀`、`x₁`，會把先前代換進來的 `x₁` 再代換一次；改成 `mpoly_substitute_all` 同時代換後才成立（代值核對把它抓出來）。
* **張量積**：25 對矩陣上 `rank(A⊗B) = rank A · rank B`；核維數 `= 列積 − rank A·rank B`；全射 ⊗ 全射 = 全射；`det(A⊗B) = det(A)^{c_B}det(B)^{r_A}`（2×2 時 `det(A)²det(B)²`，實算 100）；滿秩雅可比點上 `rank(id⊗J) = 4 = 目標維度`，奇異點上不滿射。

### 3.4 `qgeom/susy` — 超對稱四元數頂點對偶與複形四元數德朗姆幾何（28 命題）

* **分次代數**：`[A,B] = AB − (−1)^{|A||B|}BA`；分次反對稱（4² 對）、宇稱加法、**分次 Jacobi**（64 組全為零）；超跡用**實部**（`Re tr`）——因為四元數不可交換，`tr(AB) = tr(BA)` 對四元數係數不成立（1×1 分塊時退化成 `ab ≠ ba`），而 `Re tr` 成立；因此 `str(EE') = str(E'E)`、`str(OO') = −str(O'O)`、`str([A,B]) = 0`（4² 對），負控制是「一般乘積的超跡 ≠ 0」。
* **頂點對偶**：Hermitian 配對 `⟨u,w⟩ = Σ Re(conj(u_i)w_i)` 對稱、正定；**伴隨性** `⟨Au,w⟩ = ⟨u,A†w⟩`；**頂點對偶方程** `⟨A_n u, w⟩ = ⟨u, A_n† w⟩` 逐模成立（6 個模）且 `V** = V`；截斷級數乘積的結合律 `(V·W)·U = V·(W·U)`（前 3 階係數逐位元）；零階卷積就是矩陣乘積。
* **德朗姆型恆等**（5 個複形）：
  * `∂_{k−1}∂_k = 0` 精確零矩陣；
  * Betti 數實算：圓盤 `(1,0,0)` χ=1、四面體邊界 `(1,0,1)` χ=2、八面體表面 `(1,0,1)` χ=2、3×3 週期環面 `(1,2,1)` χ=0、RP² 的 6 頂點三角剖分 `(1,0,0)` χ=1；
  * `Σ(−1)^k n_k = Σ(−1)^k β_k`（兩條獨立路徑）；
  * **Hodge 定理**：`dim ker Δ_k = n_k − rank Δ_k = β_k`；
  * **超電荷恆等** `Q² = ⊕Δ_k`（矩陣逐項相等）與 `Z₂` 分次（`Q` 的偶-偶、奇-奇塊全零）；
  * 上鏈（轉置）算出的 Betti 數一致。
* **複形四元數 `H ⊗_R C`**：`i² = −1`、`J² = −1`、`(1+i)² = 2i`、共軛反自同構；環面與 RP² 在 `H ⊗ C` 上仍 `∂∂ = 0`；伴隨恆等 `⟨∂a,b⟩ = ⟨a,∂ᵗb⟩`；**複結構與邊界算子交換** `J(∂a) = ∂(Ja)`。

### 3.5 `qgeom/qk` — 四元數凱勒曲率張量群空間與雙射緊緻四元雅可比簇（39 命題）

* **`sp(2)`**：10 個基底元素全部 `X† = −X`、線性無關（秩 10）、對交換子封閉、**Jacobi**（120 組）。
* **Cartan 分解** `sp(2) = k ⊕ m`（6 + 4）：`[k,k] ⊂ k`（36 次）、`[k,m] ⊂ m`（24 次）、`[m,m] ⊂ k`（16 次）、`k ⊥ m`（36 對）、兩個 `sp(1)` 因子互相正交（9 對）。
* **四元數凱勒結構**：`sp(1)_L` 在 `m ≅ H` 上是左乘（`[X_a,M_b] = M_{σ_a·b}`，12 組）、`sp(1)_R` 是右乘（`[Y_a,M_b] = M_{−b·σ_a}`，12 組）；`I² = J² = K² = −1`、`IJ = K`、`IJK = −1`。
* **曲率的群空間落點**：`R(X,Y)Z = −[[X,Y],Z]` 落在 `m`（16 對 × 4 個 Z），而 `[X,Y] ∈ k`——「曲率取値在 `sp(1)⊕sp(n)`」在這裡是可判定的等式；曲率與 `k` 的交集**只有 0**。
* **曲率恆等式**：前兩名額反對稱、後兩名額反對稱與**配對對稱** `⟨R(X,Y)Z,W⟩ = ⟨R(Z,W)X,Y⟩`（256 組）、**第一 Bianchi**（64 組）；負控制：64 個三元組中若干非零，Bianchi 不是對零算子空轉。
* **雙射緊緻四元簇 `H^g/Λ`**：`I, J, K` 是整數矩陣、`det = 1`、`I² = J² = K² = −id`、`IJ = K`、`JK = I`、`KI = J`、`Iᵗ·id·I = id`；盒 `[−1,1]⁴` 的 81 個點在 `I` 下**每個恰好被擊中一次**；軌道分解 `81 = 1 + 4·(21 − 1)`（1 個固定點、21 條軌道）；負控制 `2I` 的行列式 16 ≠ 1。
* **極化與恆等張量幾何矩陣**：`Ω` 整數、反對稱、`det Ω = 1`；`MᵗΩM = Ω`（4 個 `Sp(2,Z)` 分塊生成元）、`g = 2` 時在 8×8 上同樣成立；`Ω(X,Y) = ⟨IX,Y⟩`；四元數 Hermitian 形式 `h(Y,X) = conj h(X,Y)`、`h(x,x) = (‖x‖²,0,0,0) > 0`；`I` 是 `ω` 的 Kähler 結構（`ω(IX,IY) = ω(X,Y)`、`ω(X,IX) = ‖x‖²`），`J`、`K` 反相容。

## 5. 邊界（不要把這裡的 `true` 讀成別的東西）

* 每個 `law_*` 回傳的是**在標籤所列的有限樣本／有限複形／固定基底上重算出來的布林**：例如「81² 對」、「5 個複形」、「4³ 組」、「16 對 × 4 個 Z」。它不是任意輸入的形式證明，也沒有被 Lean 或任何外部證明助理檢查。
* 「雅可比簇」在這裡是一個**具體的緊緻四元環面 `H^g/Λ` 模型**（`g = 1, 2`）：整數結構矩陣、單模極化、`Sp(2g,Z)` 不變的恆等張量。它不是代數曲線的 Jacobian variety，也沒有 theta 函數。
* 「超對稱」= 分次代數（`Z₂` 分次、分次交換子、超跡）＋ 有限複形上的 `Q² = Δ`。這是**數學結構**，不是量子場論模型。
* 硬體抽象層的三個後端都是**同一個 wasm 目標上的排程模擬**（走訪順序不同），不是真實 SIMD／GPU 後端；流量模型是計數模型，不是量測值。
* `moon test` 沒有被使用；本輪的檔案裡沒有任何 `test` 區塊或 `*_test.mbt`（`tools/arch_check.py` 會擋）。
